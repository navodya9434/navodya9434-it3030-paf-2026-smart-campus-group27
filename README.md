# Smart Campus Operations Hub

A full-stack web application developed using Spring Boot and React to streamline university facility bookings, resource management, maintenance requests, and incident tracking.

##  Project Overview

The Smart Campus Operations Hub is a centralized platform designed to modernize campus operations by providing efficient management of facilities, assets, bookings, maintenance requests, and notifications.

The system enables students, staff,  and administrators to interact through a secure role-based platform while maintaining transparency and auditability of all operations.

## 🚀 Features

###  Facilities & Assets Catalogue

* Manage lecture halls, laboratories, meeting rooms, and equipment
* Resource availability tracking
* Resource search and filtering
* Resource status management

###  Booking Management

* Resource booking requests
* Approval and rejection workflow
* Booking conflict detection
* Booking history management
* User and administrator booking views

###  Maintenance & Incident Ticketing

* Incident reporting
* Ticket assignment to technicians
* Status tracking workflow
* Image attachment support
* Resolution notes management
* Comment management system

###  Notifications

* Booking approval/rejection notifications
* Ticket status change notifications
* Comment notifications
* Notification center dashboard

###  Authentication & Authorization

* Google OAuth 2.0 authentication
* Role-based access control
* Protected API endpoints
* Secure route management
